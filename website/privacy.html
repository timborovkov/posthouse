Privacy

For personal, local use of Posthouse. Last updated 17 August 2026. Contact: timb.dev.

Posthouse is free, open-source software that runs on your computer or a server you control. It is not a hosted product. There is no Posthouse account and no Posthouse cloud that receives your mail or calendar content.

What Posthouse is

A personal CLI, MCP server, REST API, and optional terminal UI for operating mail and calendar connections: generic IMAP/SMTP, CalDAV, and ICS feeds, plus optional native Gmail API and Microsoft Graph sign-in on your device. You click Allow. You do not create a Google Cloud or Microsoft app.

Where your data lives

  • Mail and calendar data are stored only in the local encrypted cache on the machine where you run Posthouse, under your control.
  • Posthouse has no backend and does not send mailbox or calendar content to Posthouse servers (there are none).
  • Provider credentials and OAuth refresh tokens are stored in your OS keychain, or — if this machine has no keychain — as mode-0600 files next to the config. Those files are local secrets, not a vault, and are not encrypted with the cache key.
  • Live providers (your mail host, Google, or Microsoft if you connect them) remain the source of truth. The local cache is for bounded offline reads and sync state, not a permanent archive.

Agents and MCP

If you connect an agent through MCP (or a similar local integration), message or event content leaves your machine only because you directed that agent to read it. Posthouse does not independently upload content to third parties.

Google API services

When you choose to connect Gmail or Google Calendar, Posthouse requests only the Gmail and Calendar scopes needed to operate that connection on your device (mail uses the restricted gmail.modify scope so archive and trash work). Gmail data is not used to train models.

Posthouse’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Microsoft

When you choose to connect Outlook / Microsoft 365, Posthouse uses Microsoft Graph with delegated permissions on your device. On a machine without a browser, Microsoft supports device-code (a link and short code you Allow on your phone). Tokens stay local as described above. Posthouse does not operate a hosted OAuth redirect or token proxy.

What we do not collect

The static website for Posthouse does not require an account and is not used to process your mailbox. This policy describes the application you run locally. Analytics or hosting logs for the website, if any, are controlled by wherever you deploy these pages and are separate from mail/calendar content.
