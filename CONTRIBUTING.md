# Contributing

If something is missing, confusing, or broken, [open an issue](https://github.com/timborovkov/posthouse/issues/new). A sentence is enough. PRs are welcome too; you do not need to ask first.

Do not include passwords, tokens, message bodies, or calendar contents.

For code changes:

1. Keep the words in [CONTEXT.md](./CONTEXT.md).
2. Add a test if behavior changes. No live provider credentials.
3. Update [README.md](./README.md), [GETTING-STARTED.md](./GETTING-STARTED.md), [INSTALLATION-AND-USAGE-GUIDE.md](./INSTALLATION-AND-USAGE-GUIDE.md), or [TODO.md](./TODO.md) if user-facing behavior moved.
4. Run `make validate`.

Dev setup is in the [README](./README.md#develop). Contributions are MIT.
